## Running the Number Converter

One of the practical tasks in this assignment was creating a Python program that converts a decimal number into binary and hexadecimal representations.

The program is available inside the `mission-05-numbers-data` folder.

### Steps to run the program

**1. Open Terminal**

Navigate to the main project folder.

**2. Enter the converter folder**

```bash
cd mission-05-numbers-data
```

**3. Run the Python program**

```bash
python3 number_converter.py
```

**4. Enter a decimal number**

The program asks the user to enter a decimal number and displays its binary and hexadecimal representations.

### Example tests

| Decimal input | Binary output | Hexadecimal output |
|---:|---:|---:|
| 13 | 1101 | D |
| 25 | 11001 | 19 |
| 10 | 1010 | A |

The outputs above are examples of the expected conversions.
