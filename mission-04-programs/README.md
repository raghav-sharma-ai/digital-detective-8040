### Compiler and Interpreter Comparison

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Translates the program before execution | Executes instructions at runtime |
| Typical output | Often produces machine code or another translated form | Usually does not create a separate executable file |
| One example | C compiler (GCC) | Python interpreter |
| One advantage | Can produce a program that runs without translating the source each time | Useful for testing and running code interactively |

### Difference between a Compiler and Interpreter

A compiler translates the source program into another form before it runs. An interpreter reads and executes the instructions during runtime. A compiler often creates a separate output, while an interpreter usually executes the instructions directly. Both help the computer run programs written by programmers.
