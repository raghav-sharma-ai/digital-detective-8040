### Task 1.1 — Trace One Activity Using IPOS

**Selected activity: Typing and saving a document using a computer.**

| Stage | What happens in my example? | Hardware / Component |
|---|---|---|
| Input | I type text into a document using the keyboard. The entered characters are sent to the computer. | Keyboard |
| Processing | The computer processes the input and updates the document. The processor and memory help the application perform these operations. | CPU and RAM |
| Output | The text I have typed is displayed on the screen, allowing me to view and edit the document. | Monitor / Display |
| Storage | When I save the document, the data is stored so that I can access it later. | SSD / Storage device |

**Explanation:**

The IPOS cycle describes how a computer works with data. In this example, the keyboard provides input, the processor and memory help process the data, the display provides output, and the storage device saves the document.

This allows me to enter information, view the result, and access the saved document later.

## 4. My Understanding

Through this mission, I understood that a computer is a combination of hardware and software.

Hardware consists of the physical components of a computer, while software provides the instructions that allow the hardware to perform useful tasks.

I also understood the IPOS cycle and how it is involved in everyday computer activities. Whenever I enter data into a computer, the system processes the information, provides an output, and may store the result for future use.

Another important learning was that computer-based systems are not limited to laptops and mobile phones. Devices such as ATMs, smart TVs, and traffic signals also use computing to perform specific tasks.
